项目一句话介绍
产品定义
这是一款基于 Apple Watch 健康数据和 Gemini AI 的智能健身决策 App，通过食物拍照识别、肌肉恢复分析、训练计划推荐和 AI Coach，帮助用户每天决定：今天该怎么练、怎么吃、哪些肌肉需要恢复。

产品不是普通健身记录软件，也不是单纯卡路里计算器，而是一个每天给出健身决策的 AI 私人教练。
核心问题 1：今天能不能练？应该练哪块肌肉？
核心问题 2：今天该怎么练？动作、强度和训练日如何安排？
核心问题 3：今天该怎么吃？热量、蛋白质、碳水和脂肪还差多少？
核心问题 4：为什么系统这样推荐？AI Coach 需要给出清楚原因。
产品定位与核心价值
推荐产品定位：AI Fitness Decision Coach。中文可以叫“AI 健身决策教练”或“智能健身恢复与饮食教练”。

Apple Watch / HealthKit 数据使用方案
Apple Watch 不能直接检测某一块肌肉是否恢复。正确表达是：基于 HealthKit 数据和训练记录，对肌肉恢复状态进行智能估算。

训练强度和恢复状态
训练心率越高，恢复需求可能越高

反映身体恢复/压力趋势
HRV 低于基线时延长恢复时间

重要实现原则
HealthKit 权限必须明确说明用途；只读取必要数据；用户可以随时关闭授权；不要在界面中声称“医学诊断”或“精准检测肌肉”。

Gemini AI 接入方案
Gemini 在产品里承担两个主要角色：1）多模态食物识别；2）AI Coach 生成训练、饮食和恢复建议。
10.1 后端调用原则
不要把 Gemini API Key 写在 SwiftUI App 里。
iOS App 只调用自己的后端接口，例如 /api/meal/scan 和 /api/coach/today。
后端负责调用 Gemini、做用户权限验证、限流、缓存、日志和成本控制。
Gemini 输出必须尽量使用 JSON Schema / structured output，方便 App 稳定解析。
所有 AI 结果都要允许用户确认和修改，尤其是食物份量。
10.2 Gemini 食物识别 Prompt
You are a nutrition image recognition assistant.Analyze the meal image and identify visible foods.Estimate portion size in grams when possible.Return only valid JSON following the provided schema.Rules:- If portion size is uncertain, set needs_user_confirmation to true.- Do not provide medical diagnosis.- Include confidence scores for each food item.- Ask clarification questions when oil, sauce, cooking method, or portion size is unclear.- Prefer common food names that can be matched to a nutrition database.- Do not invent hidden ingredients unless visually likely.
10.3 食物识别 JSON 输出格式
{  "meal_name": "Chicken breast with rice and broccoli",  "meal_type": "lunch",  "foods": [    {      "name": "chicken breast",      "estimated_weight_g": 180,      "confidence": 0.86,      "portion_note": "about one medium chicken breast"    },    {      "name": "white rice",      "estimated_weight_g": 150,      "confidence": 0.75,      "portion_note": "about one small bowl"    }  ],  "needs_user_confirmation": true,  "questions": [    "Was the chicken cooked with oil?",    "Is the rice portion closer to a small, medium, or large bowl?"  ]}
10.4 AI Coach Prompt
You are an AI fitness coach.Use the user's workout data, nutrition data, recovery status, sleep, HRV, heart rate, and goals to provide practical fitness advice.Rules:- Do not claim medical diagnosis.- Keep advice concise and actionable.- Explain the reason behind each recommendation.- Provide today's training recommendation, nutrition recommendation, recovery advice, and risk warning.- If data is missing, say what is missing and give a conservative recommendation.- Avoid extreme diet or unsafe training advice.
食物拍照识别与营养计算方案
不要让 Gemini 直接负责最终营养计算。更稳定的方案是：Gemini 识别食物和份量，营养数据库负责营养数据，App/后端负责计算。
用户拍照-&gt; App 压缩图片并上传后端-&gt; 后端调用 Gemini Vision 识别食物和估算克数-&gt; 后端匹配营养数据库-&gt; 计算 calories / protein / carbs / fat-&gt; 返回 App-&gt; 用户确认/修改份量-&gt; 保存到 Daily Nutrition-&gt; AI Coach 更新今日建议

肌肉恢复计算逻辑

12.1 肌肉疲劳分数
Muscle Fatigue Score =Exercise Load x Muscle Contribution x Intensity Factor x Volume Factor x Health ModifierExercise Load: 动作负荷，可由 sets、reps、weight、duration 估算Muscle Contribution: 动作对不同肌肉的参与比例Intensity Factor: RPE 和训练心率修正Volume Factor: 总训练量修正Health Modifier: HRV、睡眠、静息心率等 Apple Watch 数据修正

订阅功能要清楚标注免费额度和 Pro 权益。
