# UI Polish Checklist

## Visual System
- [ ] Gradients/background feel consistent on all tabs.
- [ ] Card spacing and corner radius are consistent.
- [ ] Accent colors match fitness-tech style and pass dark-mode contrast.

## Home
- [ ] Readiness score animates smoothly when data changes.
- [ ] Heatmap front/back toggle feels responsive.
- [ ] Training and nutrition cards are readable at a glance.

## Recovery
- [ ] Fatigue rows are scan-friendly.
- [ ] Status colors are semantically correct (green/yellow/red/gray).

## Workout / Nutrition
- [ ] Inputs use consistent custom field styling.
- [ ] Primary actions are visually prominent.
- [ ] Save/scan feedback appears quickly and clearly.

## Coach
- [ ] Card hierarchy is clear: readiness -> training -> nutrition -> recovery -> warnings.
- [ ] Refresh interaction provides visible feedback.

## Navigation
- [ ] Custom tab bar selected state is obvious.
- [ ] Tab transitions feel smooth (no visual jumps).
