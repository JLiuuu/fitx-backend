# FitX – AI-Powered iOS Fitness Coach

FitX is an iOS fitness assistant built with SwiftUI and integrated with Google's Gemini AI.

## Features
- AI-powered conversational fitness assistance
- Multimodal food image recognition using Gemini
- Interactive iOS interface built with SwiftUI
- Asynchronous API communication, response parsing, and error handling

## Tech Stack
- Swift and SwiftUI
- Python backend
- Google Gemini API
- Xcode and iOS Simulator

## Project Status
Working prototype tested in the iOS Simulator. Gemini-powered chat and food-image recognition have been implemented. Apple Watch integration is not implemented.
